# karaoke-cli 1.0.2

Fixes GPU transcription and adds Whisper progress reporting.

## Fixes and improvements

- Whisper now uses the same `--device` as separation instead of always running
  on CPU. With the CUDA build, `--device cuda` applies to both stages; unavailable
  devices remain errors, with no silent CPU fallback.
- Updated `candle-roformer` to 1.0.1. Transcription reports the selected device,
  percentage, processed/total audio seconds, elapsed time and completion.
  Progress advances after each Whisper window (up to 30 seconds of audio),
  not on a wall-clock timer. Model loading, preparation and language detection
  may take time without advancing the percentage. Short inputs normally report
  only 0% and 100%. These messages use the info log level.
- Releases now include a separate Windows x86_64 CUDA 12.8 archive with the
  required redistributable CUDA DLLs and their license. CPU archives remain
  available for Windows and Linux. All archives have SHA-256 sidecars.

## Windows CUDA requirements

- NVIDIA Turing or newer, compute capability 7.5+ (e.g. GTX 16 / RTX 20 or later).
- NVIDIA Windows driver supporting CUDA 12.8 (570.65 or newer).
- Extract all files from `karaoke-cli-v1.0.2-windows-x86_64-cuda12.zip`
  into the same directory and run with `--device cuda`.
- CUDA Toolkit is not required on the user's machine. Models are downloaded
  separately, as before.

## Verification and limits

- Local CPU tests pass, including CLI transcription progress and sidecar output.
- Release CI tests and smoke-tests CPU binaries, and builds/packages the CUDA
  archive. The hosted runner has no GPU: CUDA inference has not been validated
  there. A successful build does not establish transcription quality.
