# karaoke-cli 1.0.4

Improves WAV saving and console visibility, and supports instrumental audio plus
lyrics without saving a vocal audio file.

## Fixes and improvements

- `--single_stem instrumental --transcribe` now saves only instrumental audio
  and lyric `.txt`/`.json` sidecars. Whisper still uses the vocal stem internally,
  never the instrumental. Sidecars share the instrumental basename, including
  custom names. Their paths are included in the early output-conflict check.
- CLI WAV output uses a bounded 256 KiB buffer rather than writing each
  four-byte sample directly to disk. IEEE-float32 WAV output remains byte-for-byte
  equivalent; no quantization or quality change. Write and flush errors propagate.
- Normal console logs use local `HH:MM:SS` timestamps instead of Unix timestamps.
  Chunk and phase elapsed times use readable seconds, minutes and hours.
- Model loading, decoding, separation, transcription, Whisper cleanup, and
  per-file saving report their active stage every 10 seconds during long
  operations. This is a liveness indication, not a completion percentage.
- Output saving reports each file's writing/encoding start, preparation time,
  installation, and overall completion. Transcription reaching 100% no longer
  leaves the saving phase silent.
- These messages are available without `--debug`; `--log_level warn|error|off`
  suppresses info-level status.

## Instrumental and lyrics

Add these options to the usual model/input command:

```text
--single_stem instrumental --transcribe --whisper_model_dir <whisper-dir> --language ru
```

No vocal audio file is written. For HyperACE v2 Inst, use converted fp32 weights
with the adapted `bs_roformer_hyperace_v2_inst.yaml` profile from candle-roformer
1.0.2, preserving its explicit family and instrumental training target.

## Downloads and verification

- Windows CPU, Windows CUDA 12.8 and Linux CPU archives with SHA-256 sidecars.
  CUDA requirements are unchanged: NVIDIA Turing or newer, compute capability
  7.5+, Windows driver supporting CUDA 12.8 (570.65 or newer).
  Extract all files from the CUDA archive together; select `--device cuda`.
- All 36 local CPU tests pass. Tests cover console message order and timestamps,
  instrumental-only audio with lyrics, WAV byte equivalence, batched writes and
  disk error propagation.
- The buffered-writer test reduces 200,000 sample writes to four underlying
  writes. Actual disk speedup depends on the machine and storage.
- Hosted release runners build/package CUDA but do not verify GPU inference.
