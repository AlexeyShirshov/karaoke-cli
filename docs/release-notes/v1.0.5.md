# karaoke-cli 1.0.5

Adds an interactive wizard, automatic model preparation, and a cleaner portable
Windows CUDA layout.

## Changes

- Running without arguments in a terminal opens a Russian-language wizard.
  `--wizard` opens it explicitly. Choose audio files/folders, a model, download
  permission, Whisper/language, device, output format, stems, chunks and overwrite
  behavior. Downloads/processing require a final confirmation; `:q` cancels.
  Redirected bare launches stay non-interactive.
- The wizard displays a reusable multiline PowerShell command on Windows or Bash
  command on Linux/macOS, with shell-specific quoting for spaces, apostrophes and
  metacharacters. Chunk prompts explain what processing in parts means.
- `--download_models` automatically prepares missing built-in weights and matching
  profiles in `./models`, without a user manifest. Short names include
  `mbr_instfv6n_gabox`, `hyperace`, `viperx`, `voc_fv7`, and `melband`.
  Explicit paths and model directory overrides remain supported.
- Published `.ckpt` sources are SHA-256 checked and converted natively to F32
  safetensors without Python. Tensor names/shapes and finite values are checked
  before installing the output. Source checkpoints are cached for retries.
  Transfers use temporary files and never overwrite existing model assets.
- `--transcribe --download_models --whisper_size large-v3` can also prepare
  Whisper automatically. The default download variant is `small`; each variant
  gets its own `models/whisper-<size>` directory. Listing models and diagnostics
  remain offline.
- With no audio arguments, `--model <name> --download_models` prepares models only.
- **Default output directory is now `./out` in both CLI and wizard.** It is
  relative to the current working directory, not the EXE or input file.
  Use `--output_dir .` to retain the previous CLI behavior.
- `--version`, `-V`, and the help header include both the CLI and candle-roformer
  versions.
- Windows CUDA archives now contain only `karaoke-cli.exe` at the root; DLLs,
  CUDA license and runtime notes are under `bin`. Early initialization makes
  CUDA DLLs available before nvcc's startup constructors. Preserve that layout.
- Removed the repetitive `still working: loading Whisper / transcribing vocals`
  messages. Transcription percentages and start/completion logs remain.

## Examples

```powershell
.\karaoke-cli.exe
.\karaoke-cli.exe --model mbr_instfv6n_gabox --download_models
.\karaoke-cli.exe "song.mp3" --model mbr_instfv6n_gabox --download_models --device cuda --single_stem instrumental --transcribe --whisper_size large-v3 --language ru
```

## Downloads and verification

- Windows CPU, Windows CUDA 12.8, and Linux CPU archives with SHA-256 sidecars.
- CUDA requirements remain NVIDIA Turing or newer (compute capability 7.5+) and
  a driver supporting CUDA 12.8 (Windows 570.65 or newer). The NVIDIA driver is
  not bundled; installing CUDA Toolkit is unnecessary.
- 63 local automated tests pass, including a real PowerShell quoting roundtrip,
  wizard processing, cached downloads, transfer/hash failures, and native
  checkpoint conversion. One additional real-asset test is opt-in.
- Native conversion was also compared tensor-for-tensor against real Gabox
  Inst FV6N and HyperACE v2 Inst safetensors. A local CUDA build starts and
  reports CUDA available; the user tested the CUDA build before this release.
  Hosted release runners still do not verify GPU inference.
